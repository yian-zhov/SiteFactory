上个月帮一位在东莞做模具的朋友处理工伤，他从车间台阶摔下来，右腿胫骨骨折，公司HR第一句话是"这属于你自己不小心，走医保吧"。我陪他跑了一趟人社局窗口，前后三个月拿到认定书和九级伤残鉴定结论，最后拿到的钱比公司最初口头承诺的多了将近七万。

这件事让我意识到，大部分人对工伤的认知停留在"上班受伤就算"，但现实里，"算不算"和"赔多少"是两套完全独立的规则。前者叫工伤认定标准，后者叫劳动能力鉴定加赔偿计算。这两关任何一关走错，钱就可能少一大截。

这篇我把2025年仍然在用的流程（主要依据《工伤保险条例》2010年修订版，以及2025年各省陆续调整的赔偿基数）完整拆一遍，包括我自己跑窗口时踩过的坑。

## 工伤认定标准：三条路径，只有一条是"绝对算"

《工伤保险条例》第十四条到第十六条把所有情形分成了三类：应当认定为工伤、视同工伤、不得认定为工伤。很多人只记得"工作时间工作场所因工作原因"，但那只是第一类里的一条。

### 应当认定为工伤的七种情形

第十四条列了七项，我用工厂和办公室场景翻译一下：

1. **工作时间+工作场所+工作原因**导致的事故伤害。这是最核心的一条，三个"工作"缺一不可。
2. **工作时间前后在工作场所内**，从事与工作有关的预备性或收尾性工作受伤。比如提前到岗开机器、下班后清理工位。
3. **工作时间+工作场所内**，因履行工作职责受到暴力等意外伤害。比如保安被闹事者打伤。
4. **患职业病**。需要职业病诊断机构出具证明，不是普通医院说一句"疑似"就行。
5. **因工外出期间**，由于工作原因受伤或发生事故下落不明。
6. **上下班途中**，受到非本人主要责任的交通事故，或城市轨道交通、客运轮渡、火车事故伤害。
7. 法律行政法规规定应当认定为工伤的其他情形。

第六条是被误解最多的一条。**必须是交通事故，且本人不负主要责任**。你自己骑电动车摔了，没有对方车辆，交警开不出事故责任认定书，这条路基本走不通。

### 视同工伤的三种情形

第十五条是"视同"，意思是虽然不是典型工伤，但法律给你同等对待：

- 在工作时间和工作岗位，**突发疾病死亡**，或在**48小时之内**经抢救无效死亡；
- 在**抢险救灾**等维护国家利益、公共利益活动中受伤；
- 职工原在军队服役，因战、因公负伤致残，已取得革命伤残军人证，到用人单位后旧伤复发。

48小时这个数字是硬线。我查过中国裁判文书网2024年的相关案例，起算点是**医疗机构的初次诊断时间**，不是发病时间，也不是送医时间。这个细节常常决定家属能不能拿到工亡待遇（一次性工亡补助金2025年是全国统一标准，下文会算）。

### 绝对不算的三种

第十六条排除：故意犯罪、醉酒或吸毒、自残或自杀。注意"醉酒"的认定通常要血液酒精检测，公司拿不出检测报告，不能随口说你喝了酒。

## 上班受伤算不算工伤？我整理了一张判断表

| 情形 | 是否工伤 | 关键判断点 | 常见误区 |
|---|---|---|---|
| 车间操作机器切伤手指 | 是 | 工作时间+场所+原因 | 无 |
| 下班顺路买菜被车撞，本人无责 | 是 | 属于"合理路线"的日常所需 | 以为绕路就不算 |
| 下班回家途中自己骑车摔伤 | 否 | 无第三方，不构成交通事故责任 | 以为"上下班途中"万能 |
| 上班时和同事争执被打伤 | 看情况 | 是否因履行工作职责 | 私人恩怨不算 |
| 加班到深夜猝死，48小时内抢救无效 | 视同工伤 | 初次诊断时间起算 | 超过48小时家属常放弃 |
| 团建爬山摔伤 | 争议大 | 活动是否单位强制组织 | 自愿参加的常被驳回 |
| 中午食堂吃饭噎住 | 通常否 | 与工作无直接因果 | — |
| 出差住酒店洗澡摔伤 | 一般算 | 因工外出的合理延伸 | 需证明与出差关联 |

这张表是我根据判决书和窗口咨询经验整理的，不是法条原文。第七行、第六行这类边界案例，各地人社局口径确实存在差异，后面会讲。

## 工伤认定流程：一年时限，晚一天就没了

这是整件事里最要命的部分。很多人受伤后先养病，等想起来申请，时限已经过了。

### 谁申请、什么时候申请

- **用人单位**：事故伤害发生之日或被诊断为职业病之日起**30日内**，向统筹地区社会保险行政部门提出。遇特殊情况经同意可适当延长。
- **职工或近亲属、工会组织**：用人单位不申请的，可在**1年内**直接申请。

**这1年是除斥期间性质，一般不可中断、不可延长。** 我见过一个案例，职工因为和公司协商赔偿谈了一年多，等谈崩了再去申请，人社局直接以超期驳回，一分钱没有。

所以我的建议是：无论公司态度多好，**受伤后30天内先自己把申请递上去**，认定和赔偿是两件事，认定不影响后续协商。

### 需要提交的材料

我陪朋友跑窗口时，工作人员给了一张清单，这里照录：

1. 工伤认定申请表（窗口领取或人社局官网下载）
2. 与用人单位存在劳动关系的证明材料
   - 劳动合同原件及复印件
   - 无合同的：工资流水、考勤记录、工牌、微信工作群记录等
3. 医疗诊断证明或职业病诊断证明书（原件）
4. 受伤职工身份证复印件
5. 目击证人证言（2人以上，附身份证复印件和联系方式）
6. 特殊情形附加材料：
   - 交通事故：交警事故责任认定书
   - 暴力伤害：公安机关证明或法院判决
   - 因工外出：单位派遣证明、行程记录
   - 突发疾病：医疗机构的抢救记录、死亡证明

第2项是无劳动合同情况下的死穴。这里可以看我之前写的[公司不交社保怎么办？三种维权途径全解析](/posts/company-not-paying-social-insurance-ways/)，里面讲到的事实劳动关系举证思路完全通用——工资流水、考勤、工作群聊天记录都可以用。

### 受理后的时间线

| 环节 | 法定期限 | 实操经验 |
|---|---|---|
| 受理决定 | 收到申请后15日内 | 材料不齐会一次性告知补正 |
| 作出认定决定 | 受理之日起60日内 | 事实清楚的15日内可出 |
| 送达决定书 | 作出后20日内 | 会同时送达职工和单位 |
| 对结论不服 | 60日内复议 / 6个月内诉讼 | 单位不服也能起诉，拖时间是常态 |

**60日**是法定上限，不是承诺。我朋友在东莞的实际等待是41天出认定书。但如果是争议案件（比如单位否认劳动关系），会先走劳动仲裁确认关系，整个周期可能拉到半年以上。

### 一个实操细节：送达地址

申请表上有一栏"送达地址"，务必填一个你**长期能收到快递**的地址，不要填宿舍或者临时租的房子。认定书是后续所有流程的起点，丢了补办很麻烦。

## 劳动能力鉴定：赔偿金额的真正分水岭

拿到工伤认定书只是拿到了入场券。真正决定赔多少钱的是**劳动能力鉴定**，也就是伤残等级。

流程是：认定工伤后，伤情相对稳定（一般治疗终结），由用人单位、工伤职工或其近亲属向设区的市级劳动能力鉴定委员会申请。委员会从医疗卫生专家库中随机抽取专家，一般60日内作出结论，必要时可延长30日。

伤残等级分1到10级，**1级最重，10级最轻**。等级直接决定三笔钱：

- **一次性伤残补助金**（基金支付，全国统一按本人工资倍数）
- **一次性工伤医疗补助金**（解除劳动关系时，基金支付，各省标准）
- **一次性伤残就业补助金**（解除劳动关系时，单位支付，各省标准）

先看全国统一的那笔：

| 伤残等级 | 一次性伤残补助金（本人工资倍数） | 备注 |
|---|---|---|
| 一级 | 27个月 | 保留劳动关系，退出岗位 |
| 二级 | 25个月 | 同上 |
| 三级 | 23个月 | 同上 |
| 四级 | 21个月 | 同上 |
| 五级 | 18个月 | 可保留关系或解除 |
| 六级 | 16个月 | 同上 |
| 七级 | 13个月 | 可解除 |
| 八级 | 11个月 | 同上 |
| 九级 | 9个月 | 同上 |
| 十级 | 7个月 | 同上 |

后两笔（医疗补助金+就业补助金）是**省级标准**，各地差距很大。比如同样是十级，广东和江苏的数字就不一样，同一省内不同年份也可能调整。所以网上那些"工伤十级赔多少"的固定答案基本不可信，必须查你所在省的最新文件。

## 工伤赔偿计算：三个真实数字带你看

我把公式和案例放一起。**本人工资**是核心变量，指工伤职工因工作遭受事故伤害或患职业病前12个月平均月缴费工资。注意是**缴费工资**，很多公司按最低基数缴，会导致赔偿缩水，这一点下面单独说。

### 案例一：九级伤残，月薪8000，广东

朋友的情况，简化数据：

本人工资：8000元/月
伤残等级：九级
一次性伤残补助金 = 8000 × 9 = 72,000元（基金支付）
医疗补助金 + 就业补助金（广东九级标准，按上年省平工资计算）
假设合计约 8 个月本人工资 = 64,000元
停工留薪期工资：治疗期间原工资待遇不变

加上停工留薪期几个月的全额工资，总盘子比公司最初"给你三万私了"的报价高出一大截。这也是为什么我说**别急着签私了协议**。

### 案例二：十级伤残，月薪5000，江苏

一次性伤残补助金 = 5000 × 7 = 35,000元
一次性工伤医疗补助金 + 一次性伤残就业补助金
（江苏十级合计约数万元，按当地上年职工月平均工资标准）

十级是最常见的伤情等级（比如轻度骨折、部分手指功能受损），很多人以为"这么轻没什么钱"，实际加上两笔补助金，总额往往超过五万。

### 案例三：工亡待遇，2025年全国标准

工亡待遇由三部分组成，其中一次性工亡补助金是**全国统一**的：

一次性工亡补助金 = 上一年度全国城镇居民人均可支配收入 × 20
2025年适用的是2024年全国城镇居民人均可支配收入 54,188 元
54,188 × 20 = 1,083,760 元

这个数字每年3月左右随国家统计局数据更新。另外还有丧葬补助金（6个月统筹地区上年度职工月平均工资）和供养亲属抚恤金（按本人工资的一定比例按月发放）。

需要提醒：**48小时内抢救无效死亡才能走工亡**，超过48小时去世但未被认定为工亡的，家属只能走普通工伤或主张其他责任，落差非常大。这里涉及医疗期和证据固定，思路和[人身损害误工费赔偿标准](/posts/lost-wages-personal-injury-compensation/)里讲的收入损失举证是相通的。

## 三个最容易吃亏的地方

### 陷阱一：公司按最低基数缴社保

赔偿里的"本人工资"以**缴费工资**为准，不是你的实发工资。如果公司长期按最低档给你缴，出事后赔偿基数会被拉低。遇到这种情况，需要提供工资流水证明实际工资，主张按实际工资计算。举证逻辑和我在[公司拖欠工资，除了仲裁还能怎么办？](/posts/wage-arrears-legal-remedies/)里提到的一样——银行流水是最硬的证据。

### 陷阱二：被迫签"自愿放弃"协议

有些公司会在你住院期间拿来一份协议，说"先给你X万，签了就别再申请工伤了"。这类协议如果是在你**未做伤残鉴定、不清楚法定标准**的情况下签的，且金额明显低于法定标准，可以主张撤销或认定部分无效。别在病床上签字，这是我最想强调的一条。

### 陷阱三：超过1年申请时限

前面说过，1年是硬线。我见过太多人是被公司"我们会负责"拖过时限的。记住：**协商归协商，认定归认定，两条线并行不冲突。**

## 赔偿谈不拢怎么办：仲裁是必经之路

如果单位不配合或者金额谈不拢，路径是：

1. **劳动仲裁**（前置程序，不能直接起诉），主张工伤待遇差额；
2. 对仲裁裁决不服，15日内向法院起诉；
3. 单位不履行生效裁决，申请强制执行。

仲裁的时效是从你知道权利被侵害之日起1年。流程本身可以参考[劳动仲裁全流程指南：从申请到裁决究竟要多久？](/posts/labor-arbitration-full-process-guide/)，工伤案件的仲裁和普通劳动争议在程序上完全一样，只是多了工伤认定书和鉴定结论两份核心材料。

如果你经济困难请不起律师，可以看[法律援助申请指南](/posts/post-e36579a8d5d9c6e/)，工伤案件属于典型的可申请法律援助范围。

## 几个高频疑问

**问：没有劳动合同能认定工伤吗？**

能，但要先确认事实劳动关系。用工资流水、考勤、工作群记录、同事证言等材料。这也是为什么我一直建议保存这些证据。

**问：认定书下来了，公司不认怎么办？**

公司可以申请行政复议或提起行政诉讼，这会拖时间，但**不影响你按认定结论主张待遇**，除非结论被撤销。

**问：伤残等级多久能重新鉴定？**

自劳动能力鉴定结论作出之日起1年后，伤情发生变化的，可以申请复查鉴定。

**问：异地打工受伤，在哪申请？**

在**参保地**申请；未参保的，在**用人单位所在地**申请。跨省务工这点要特别注意，别跑错地方白等。

**问：停工留薪期有多长？**

一般根据伤情由医疗机构出具意见，通常不超过12个月；伤情严重的经鉴定委员会确认可延长，但延长不超过12个月。

---

回过头看，整个流程其实就三步：**认定 → 鉴定 → 算钱**。难的不是法律条文，而是时限意识和证据意识。时间窗只有1年，证据散落在工资流水和微信群里，任何一环松了，钱都会少。

我的建议很简单：受伤后第一周就把材料清单列出来，30天内把申请递上去，无论公司态度多好。认定书在手，你才有谈判的底气。
